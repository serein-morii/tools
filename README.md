## 功能特性

### 🚀 首次配置引导
- 应用首次启动自动进入配置引导页
- 分步引导配置 GitLab 连接和 Walkin 代码质量平台
- GitLab 步骤支持连接测试，Walkin 步骤支持自动登录
- 验证码手动输入
- 支持跳过、稍后在设置中配置

### 📊 概览面板
- 五大模块状态一览：提醒任务、通知渠道、扫描记录、变更项目、发送成功率
- 可展开详情：未来 7 天任务、最近扫描、贡献者 Top 3、覆盖率看板、发送历史
- 全局刷新按钮
- 快速入口网格：跳转到各功能模块

### 📋 任务提醒
- 多种 Cron 表达式格式（标准、特殊日期、高级）
- 本地时间语义：时间表达式按本地时区解释
- 任务优先级（普通 / 重要 / 紧急）
- 提醒类型：简单通知、需要确认、需要反馈
- 关联模板 + 多通知渠道
- 一键测试通知发送

### 📢 通知渠道
- **Bark**: iOS 推送通知
- **飞书**: 群机器人 Webhook
- **企业微信**: 群机器人 Webhook
- **钉钉**: 群机器人 Webhook（支持 @ 指定用户）
- 自定义服务器地址
- 一键测试通知发送

### 🔍 GitLab 代码扫描
- 多 Token 支持，可同时使用多个 GitLab 账号
- 项目过滤：包含 / 排除模式，支持通配符
- 单测检测：自动识别测试提交
- 定时扫描：Cron 表达式自动调度
- **概览面板**：
  - 趋势分析图表（提交数 + 增量覆盖率）
  - 本周贡献 TOP5 排名
  - 团队覆盖率看板（Walkin 集成）
  - 项目列表：可排序、可筛选、可展开查看详情
  - 项目详情：MR 列表、流水线状态、质量评级（可靠性 / 安全性 / 可维护性）
- **历史记录**：
  - 扫描历史列表，支持搜索和类型筛选
  - 两次扫描对比视图
  - 扫描详情弹窗：流水线统计、开发者 MR 贡献、项目详情
- **Walkin 集成**：
  - RSA 公钥加密登录，验证码自动识别
  - 代码质量数据：Bug、漏洞、异味、重复率
  - 增量 / 全量覆盖率（综合、行、条件）
  - 质量评级：可靠性、安全性、可维护性

### 🧪 单测覆盖率
- 团队覆盖率看板（综合 / 行 / 条件 / 增量 / 全量）
- 应用列表详细指标：
  - 综合覆盖率（增量 + 全量）
  - 行覆盖（行数 / 已覆盖数 / 行覆盖率）
  - 条件 / 分支覆盖（条件数 / 已覆盖数 / 条件覆盖率）
  - 构建日期、构建人
  - 覆盖率低于阈值时高亮告警
- 单测提交记录追踪
- **Prompt 生成**：根据未覆盖代码行自动生成单测提示词
- **模板管理**：可复用的 Prompt 模板（变量占位符 `{file_list}`）
- **生成历史**：本地保存生成记录，支持加载历史配置

### 🤖 AI 生成率
- AI 代码生成率统计
- 按作者维度分析
- 提交详情查看

### 📝 消息模板
- 可复用的消息模板
- 支持变量替换：`{task_name}`, `{date}`, `{time}`, `{weekday}` 等
- 默认 Cron 设置

### 📊 提醒历史
- 完整的执行记录追踪
- 支持确认完成、提交反馈、稍后提醒
- 状态过滤和搜索

### 🎛️ 系统设置
- 主题切换（浅色 / 深色 / 跟随系统）
- 多语言支持（中文、英文、日语、韩语）
- 开机自启动（可选静默启动）
- 最小化到托盘，托盘菜单支持新建任务 / 扫描代码 / 打开概览 / 打开设置
- 菜单页面排序与显隐控制
- 启动页选择
- 数据备份与恢复（JSON 格式导入导出）
- 配置引导重新打开
- 危险操作区域（重置配置、清除缓存，带二次确认）

## 技术栈

- **前端**: React 19 + TypeScript + Vite + TailwindCSS + shadcn/ui
- **后端**: Rust + Tauri v2 + SQLite
- **状态管理**: TanStack Query
- **国际化**: react-i18next（4 语言：中 / 英 / 日 / 韩）
- **加密**: RSA 公钥加密（Walkin 登录）
- **调度**: tokio 异步 + cron 表达式

## 安装与构建

### 前置要求

- Node.js 18+
- Rust 1.77.2+
- pnpm 11+

### 开发环境

```bash
# 克隆项目
git clone https://github.com/serein-morii/tools.git
cd tools

# 安装依赖
pnpm install

# 启动开发模式
pnpm tauri dev
```

### 构建

```bash
# 构建生产版本
pnpm tauri build
```

## Cron 表达式支持

### 标准格式

- 每天：`0 9 * * *`（每天 9:00）
- 每周：`0 9 * * 1`（每周一 9:00）
- 每月：`0 9 1 * *`（每月 1 日 9:00）
- 每年：`0 9 1 1 *`（每年 1 月 1 日 9:00）

### 特殊日期

- 第 N 个星期几：每月第 3 个周一
- 倒数第 N 天：每月倒数第 3 天
- 最后一个工作日：每月最后一个工作日
- 时间间隔：每 15 分钟

### 结束条件

- 永不结束
- 执行 N 次后结束
- 指定日期后结束

## 数据备份

通过「设置 → 数据管理」可导出全部数据为 JSON 文件，包含：
- 任务（tasks）
- 通知渠道（channels）
- 消息模板（templates）
- 设置（settings）

导入时按版本号校验，不匹配会拒绝导入。
